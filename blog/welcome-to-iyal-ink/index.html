Moving Away from Bizarre Formats

Over the years, screenwriting software has often drifted toward bizarre, closed file formats. If you open a screenplay saved in some of these formats outside the specific application that created it, all you see is binary clutter. If that software isn't installed, reading your own work becomes unnecessarily complex.

Furthermore, many modern writing suites push mandatory cloud synchronization by default. Every word typed travels across third-party remote servers before landing on disk. In an era where creative intellectual property privacy is paramount, relying on cloud-first tools creates unnecessary friction for writers.

We asked ourselves: Why should a screenwriter on Windows or Linux settle for compromised, port-over experiences or web app wrappers? Why should macOS writers have access to dedicated native Fountain applications while PC writers are left behind? Why can't a screenplay editor be blazing fast, offline-first, portable, and beautiful?

Enter Fountain: Plain Text for Screenwriters

The foundation of everything we build at iyal.ink rests on Fountain—an open, plain-text markup syntax for screenplays. Fountain allows you to write a screenplay in any editor, on any device, using simple human-readable conventions. A scene heading starts with INT. or EXT., a character name is written in uppercase, and dialogue sits right beneath it.

ActOne Screenplay and FountTUI are both Fountain-ready applications designed to work directly with standard Fountain files. ActOne Screenplay uses the .actone format only when you need extended workspace features like multi-script project bundles, character cards, notes, and task markers. Under the hood, .actone is basically a Fountain file packaged inside a standard ZIP archive. An official converter will be available soon, but you can already open any .actone archive using standard tools like WinZip or 7-Zip, extract it, and find your raw Fountain screenplay file right inside.

  • Fountain-Ready Applications: Both FountTUI and ActOne Screenplay write plain Fountain files directly. The .actone format is used only when you need extra project bundle features, and can be extracted with WinZip anytime to get your raw Fountain file.
  • Automated Snapshot System: Built-in version history continuously creates local snapshots so you can review and restore earlier drafts instantly without cloud dependency.
  • Privacy & Local Control: ActOne Screenplay operates locally and uses the internet strictly for checking app updates and submitting crash reports—never for uploading your creative writing.

Our Ecosystem: FountTUI & ActOne Screenplay

To serve screenwriters across every workflow and preference, iyal.ink offers two distinct tools built from the ground up for Fountain:

1. FountTUI — The Minimalist Terminal Screenplay Editor

FountTUI is built for writers who crave pure, distraction-free velocity. Operating directly inside your terminal, FountTUI delivers instant start times, zero memory bloat, keyboard-driven navigation, and automatic session snapshotting to ensure you never lose a single keypress. It brings the tactile focus of a mechanical typewriter straight into the modern terminal.

2. ActOne Screenplay — The Native Fountain Screenplay Workspace for PC

While macOS users have enjoyed native Fountain apps like Highland and Beat for years, Windows and Linux screenwriters have lacked a dedicated native environment. ActOne Screenplay closes that gap. Built with React, Rust, and CodeMirror 6, ActOne Screenplay is the only native Fountain screenplay editor for Windows and Linux.

ActOne Screenplay combines live Fountain auto-formatting and syntax highlighting with a complete production workspace: hierarchical Outline Navigators for outline structure visualization, X-Ray analytical graphs for character co-occurrences, local-first AI writing assistance via Ollama, and high-performance Rust PDF generation.
