THE DESKTOP WORKSPACE

From first line
to final export.

01

Native Fountain Screenplay Editing

  • Live Formatting & Highlighting: Built-in CodeMirror 6 engine with real-time Fountain syntax coloring and clean manuscript rendering.
  • Smart Formatting Tools: Automatic line-spacing, Tab-to-cycle Fountain prefixes (@, ., >), and auto-closing wrylies/parentheticals.
  • Character Autocomplete: Real-time ghost text suggestions for character names, locations, and parentheticals.
02

Outline Tree Navigator

  • Hierarchical View: Collapsible tree structure mapping sections (#), scene headings, and synopses (=) instantly.
  • Scene Highlights & Storylines: Visual color markers and plot arc badges attached to scene headers in outline.
03

Multi-Script Projects (.actone)

  • Drafts & Assets Workspace: Package multiple plain .fountain screenplay files, local Notepad sheets, checklists, and session progress data into a single, organized folder.
  • Open ZIP Standards: ActOne bundles save as standard ZIP archives to guarantee complete ownership. A direct online .actone to .zip converter is coming soon!
04

Automatic Version Snapshots

  • Interval Backups: Auto-interval, manual, and save-triggered local snapshots keep track of every paragraph revision history.
  • One-Click Restores: Compare differences and rollback to past snapshots instantly without relying on cloud servers.
05

X-Ray Screenplay Analytics

  • Visual Pacing & Ratios: Charts displaying Dialogue-to-Action ratios, day/night scene distributions, and pacing charts.
  • Character Co-Occurrence: Interactive circle connection graphs mapping scene occurrences between screenplay characters.
06

Muse AI Writing Assistant

  • Local & Cloud Models: Connect via local Ollama instances for 100% private models or secure API keys.
  • Command Integrations: Use @write-scene, @lookup, and @synonyms directly in context-aware screenplay chat threads.
07

High-Performance Rust PDF & FDX Export

  • Rust Rendering Engine: Pixel-perfect formatting with cosmic-text rendering, customizable scene numbers, and orphan protection.
  • Final Draft Compatibility: Exports screenplay directly to Final Draft (.fdx) format, preserving section and color highlights.
