RELEASE NOTES / V0.4.6

What's new

  • Indic script support — the editor now includes Tamil, Telugu, Malayalam, Kannada, Bengali, Gujarati, Devanagari, Oriya, and Gurmukhi fonts with correct fallback rendering, including italics.
  • Cleaner non-English underlines — underlines in complex scripts display correctly in the editor and in exported PDFs.
  • Intelligent crash recovery — crashes are classified by severity: contained errors show an inline Retry bar, window failures offer Reload, and app failures offer Restart without data loss.
  • Muse status indicator — a status-bar indicator turns green when Muse is configured and red when it needs attention; one click opens the panel or Muse Settings.
  • More reliable reports — crash reports include complete system diagnostics, cleaner Discord embeds, and no false "previous session crashed" notices after a hard close.
