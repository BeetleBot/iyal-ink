RELEASE NOTES / V0.4.17

What's new

  • 🔤 Smarter Contraction Detection — Spellcheck now understands curly apostrophes like the ones in couldn't and don't, so everyday contractions are no longer wrongly flagged as typos.
  • 🎭 Your Characters, Never Flagged — Character names from your script are now automatically recognized by the spellchecker, so they won't be marked as misspelled.
  • ⚡ Faster, Quieter Spellchecking — Background spellchecking now does the heavy lifting up front and only checks what you're actively writing, making the whole app feel snappier as you type.
  • 🎨 More Polished Themes — Refined the Catppuccin color palettes across both light and dark mode for a more consistent, cohesive look.
  • 💬 Native Desktop Dialogs — Confirmation and alert pop-ups (like project structure and screenplay element imports) now use your operating system's own dialogs for a cleaner, more native experience.
  • 🔍 Cleaner Command Palette — Tidied up the Command Palette by removing redundant recent-command tracking and polishing the category headings for easier scanning.
  • 📜 Dialogue Stays Together — Fixed an import bug where dialogue and its parenthetical direction lines could get split apart when bringing in Fade In or other screenplay files.
