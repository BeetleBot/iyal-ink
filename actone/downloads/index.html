RELEASE NOTES / V0.4.10

What's new

  • Linux Caret & Selection Fix — Fixed duplicate caret and selection rendering issues on Linux by replacing CodeMirror's drawSelection with a custom cursor layer.
  • Catppuccin Mocha Theme Polish — Enhanced theme consistency across the interface with native Mocha palette colors, featuring a Mantle sidebar and darker Crust editor canvas.
  • Stutter-Free Typing & Smart Auto-Save — Auto-save detects when you are actively writing and waits until you take a natural pause before saving in the background.
  • Stability & Performance Enhancements — General stability improvements across project file handling, modal viewports, and background process management.
  • Minor Bug Fixes — Resolved various minor UI rendering edge cases and window management behaviors for a smoother desktop experience.
