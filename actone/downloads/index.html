Linux / Flatpak

Install ActOne with Flatpak.

Works across Linux distributions with Flatpak installed.

  1. Install Flatpak using the setup guide for your distribution ↗.
  2. Run this command in your terminal, then approve the installation prompts:
flatpak install --user https://flatpak.iyal.ink/actone.flatpakref

This installs ActOne and adds the iyal.ink repository. Open ActOne from your app menu. Future versions appear in your software manager.

Prefer a graphical installation?

Download actone.flatpakref and open it with KDE Discover or GNOME Software with Flatpak support. Approve the repository and install the app.

Terminal commands

Update:

flatpak update --user ink.iyal.actone

Launch:

flatpak run ink.iyal.actone

Uninstall:

flatpak uninstall --user ink.iyal.actone

v0.6.2 — PDF Preview & X-Ray Improvements

November 1, 2026

Fit Page PDF Preview: PDF previews now open with the whole page visible. Switch between Fit page, Fit width, and manual zoom. Fit page adjusts automatically when you resize the window.

Separate Paper Sheets: Clear spacing, page edges, and subtle shadows make individual preview pages easier to see.

PDF Export Layout & Scrolling: The preview fills the available space and scrolls independently from the export settings. Export buttons stay visible, and the settings column adapts to your window width.

X-Ray Window Resizing: Charts adapt to your window while keeping labels and rows readable. Panels stack in narrower windows, and shorter windows scroll without squeezing the charts.
