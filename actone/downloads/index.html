RELEASE NOTES / V0.4.13

What's new

  • Quick Guide Overlay (F1) — Pressing F1 opens the Quick Guide modal featuring sticky tabs for Keyboard Shortcuts and Fountain Syntax Reference.
  • Previous & Next Scene Navigation — Jump between scene headings rapidly with Alt+↑ / Alt+PageUp (Previous Scene) and Alt+↓ / Alt+PageDown (Next Scene).
  • Linux CodeMirror Layout Crash Fix — Refactored scroll position measurements to eliminate TypeError: undefined is not an object (evaluating 'p.top') crashes on WebKit / Linux.
  • Flatpak Packaging Improvements — Upgraded Linux distribution to standalone versioned Flatpak bundles (.flatpak).
