RELEASE NOTES / V0.4.11

What's new

  • Scene Renumbering & Clearing Fix — Fixed "Renumber Scene Headings" and "Clear Scene Numbers" in the Command Palette by dispatching document changes directly to CodeMirror's editor view.
  • Classic Dark Theme Contrast Fix — Fixed text rendering contrast on selected active items in the Classic Dark theme.
  • Enhanced Indic Script Support — Integrated font fallback chains for Indian languages including Malayalam, Hindi/Marathi, Telugu, Bengali, Gujarati, Kannada, Punjabi, and Odia.
  • Global UI Font Engine & Layout Polish — Standardized the application interface to Inter font across UI elements, fixed tab sizing in header bar, added hover delay for tooltips, and redesigned the Outline View scene cards.
