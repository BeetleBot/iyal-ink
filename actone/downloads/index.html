RELEASE NOTES / V0.4.16

What's new

  • Native Rust Spellcheck Engine — Integrated a high-performance, pure-Rust spellchecking engine (spellbook) with an embedded offline English dictionary, plus on-demand multi-language dictionary downloads.
  • Screenplay Element Awareness — Scene Headings, Character, Dual Character, and Transition lines — along with Fountain terms like INT, EXT, POV, VO, and SLUGLINE — are intelligently excluded from spellchecking.
  • Context Menu Corrections & Dictionary — Right-click any flagged typo for instant spelling suggestions, "Add '[word]' to Dictionary" (persisted across sessions), and "Ignore '[word]'".
  • Spellcheck Settings Tab & Status Bar Menu — A dedicated Spellcheck tab in Settings with master toggle, language selector, and dictionary management, plus a status bar language indicator with quick-menu.
  • Script Importers (Final Draft, Fade In & Fountain) — Import .fdx, .fadein, and .fountain files directly, with forced Fountain element formatting and instant .actone project conversion.
  • Stable Editor Pagination — Harmonized editor status bar pagination with native Rust PDF export metrics and eliminated rapid page number jumping while typing.
  • Window Size & Position Retention — The main editor window now remembers its size, position, and maximized state across sessions on Windows, Linux, and macOS.
