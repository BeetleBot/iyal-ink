02 RELEASE NOTES & CHANGELOG VERSION 0.4.21

ActOne v0.4.21

Latest Stable
Production Release
New
Gen 3 Multi-Document Project Bundles: Standardized .actone project bundles so all screenplay and prose documents are cleanly organized inside a dedicated files directory with automatic migration for older projects.
New
Automatic Script Metadata Migration: Renaming documents inside the Project Pane now automatically migrates all associated notes, tasks, parking lots, character profiles, and production tags to the new name—eliminating lost data.
New
Project Pane Right-Click Context Menu: Added instant right-click access across all document cards in the Project Pane to Rename, Move Up, Move Down, Duplicate, and Delete.
Improved
Instant 1:1 Scrollbar Pointer Tracking: Dragging the scrollbar thumb in the editor and sidebars now tracks the mouse pointer instantaneously with zero elastic lag or bounce.
Improved
Save Pipeline Data Integrity & Safety: Instant direct document saving with protection against file collisions during rapid Ctrl+S keystrokes.
Fix
Project Pane Rename Focus Fix: Resolved an issue where renaming files from the context menu could lose keyboard focus.
Fix
Streamlined Welcome Screen: Cleaned up the Welcome Screen launcher for a distraction-free, faster startup experience.
