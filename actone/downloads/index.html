02 RELEASE NOTES & CHANGELOG VERSION 0.4.24

ActOne v0.4.24

Latest Beta
Production Release
New
Quick AI Model Switcher Palette (Alt+Shift+M): Minimal, fast floating dialog to switch between custom OpenAI-compatible API models and locally running Ollama models on the fly, with quick options to disable AI or jump straight to provider configuration in Settings.
Improved
Scene-by-Scene Translation Architecture: Whole-document translation now uses narrative scene-by-scene units instead of fixed line batches, with adaptive sub-chunking for scenes exceeding 35 lines to preserve narrative context, character attributions, and emotional tone.
Improved
Cleaner Translated Screenplays: Character glossaries no longer leak leading @ symbols into AI prompts, model-generated surrounding quotes are stripped from dialogue, enclosing parentheses are stripped from action lines, and cross-lingual tokenizer bleeding (e.g. stray CJK or neighboring Indic glyphs) is automatically sanitized.
Improved
Synchronous Script State Sync: Active script state now synchronizes immediately during script duplication, deletion, creation, switching, and reordering, preventing background updates from dropping or targeting outdated scripts.
Fix
Drag-and-Drop Listener Lifecycle Guard: Hardened window event listener cleanup against Tauri TypeError: Cannot read properties of undefined (reading 'handlerId') crashes during React unmounts and hot reloads.
Improved
Leaner Bundle & Stronger Test Coverage: Removed legacy production breakdown tag data structures and CSV export routines to reduce bundle overhead, with translation engine coverage expanded to 23 tests for scene segmentation, chunking, retries, and formatting cleanup.

Linux Installation & Setup Guide

Flatpak Bundle (.flatpak)

Recommended

Flatpak provides a sandboxed, isolated runtime for modern Linux distributions.

Install: Run in terminal where downloaded:
flatpak install --user ActOne.flatpak
Run: Launch from app menu or terminal:
flatpak run ink.iyal.actone

AppImage (.AppImage)

Portable single-file executable. Can be used directly or integrated into your desktop.

Run as Portable: Make executable and run:
chmod +x ActOne.AppImage && ./ActOne.AppImage
Optional Desktop Integration:
  • On first launch, you will be prompted to install desktop integration.
  • Or install anytime via Settings → General → Desktop Integration.
