RELEASE NOTES / V0.4.6

More scripts.
More resilience.

A typography-focused release with stronger recovery, clearer status, and more dependable diagnostics.

01 / TYPOGRAPHY

Indic script support

Comprehensive Tamil, Telugu, Malayalam, Kannada, Bengali, Gujarati, Devanagari, Oriya, and Gurmukhi fonts now render correctly, including italic text and fallback typography.

02 / EXPORT

Cleaner non-English underlines

Underlines in complex scripts now stay clean and aligned across the editor and exported PDFs.

03 / RECOVERY

Intelligent crash recovery

Failures are classified by severity: contained errors show an inline Retry bar, window failures offer Reload, and app-level failures offer a full Restart without data loss.

04 / MUSE

A clearer AI status

The full-height status indicator turns green when Muse is configured and red when it needs attention. One click opens the panel or Muse Settings, with a cleaner two-command palette.

05 / DIAGNOSTICS

More reliable reports

Crash reports now include complete system diagnostics, cleaner Discord embeds, and accurate previous-session recovery notices after hard closes.
