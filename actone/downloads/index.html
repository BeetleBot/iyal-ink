A little help getting settled

Linux installation.

Use the recommended Flatpak repository for updates, or follow the steps for a standalone download.

Install from the Flatpak repository (recommended)

With Flatpak installed, run this command in your terminal and approve the installation prompts:

flatpak install --user https://flatpak.iyal.ink/actone.flatpakref

Future updates appear in your software manager. You can also update from a terminal:

flatpak update --user ink.iyal.actone
Install a downloaded Flatpak bundle

Open a terminal in the download folder. Replace the filename if your downloaded bundle has a different name.

flatpak install --user ActOne.flatpak

Launch from your app menu, or run:

flatpak run ink.iyal.actone
Run an AppImage

Allow the downloaded file to run as a program in its properties, then open it. Or, in its folder, run the following with your downloaded filename:

chmod +x ActOne.AppImage
./ActOne.AppImage
