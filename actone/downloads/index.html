v0.5.5 Release Highlights

Rebuilt X-Ray Story Atlas: Compact visual dashboard with stacked scene-rhythm bars, dialogue/action rings, character rankings, speaking presence heatmap, shared-scene matrix, and location/time charts.

Interactive Scene & Cast Exploration: Select chart marks to inspect scene details, jump to script, or edit character profiles, with scene search and compact pagination.

Visual Analysis PDF Export: Export a paginated atlas of charts, scenes, cast breakdowns, and connections with high-resolution graphics and print palette.

PDF Export Crash Fix: Resolved PDF export subsetter failure caused by orphan Indic combining marks with automated Unicode Indic sanitization.

Rupee Symbol PDF Support: Routed Indian Rupee symbol (₹) to bundled symbol fallback font for clean PDF export.

A little help getting settled

Linux installation.

Download a package from the release page, then follow the steps for your format.

Install a Flatpak bundle

Open a terminal in the download folder. Replace the filename if your downloaded bundle has a different name.

flatpak install --user ActOne.flatpak

Launch from your app menu, or run:

flatpak run ink.iyal.actone
Run an AppImage

Allow the downloaded file to run as a program in its properties, then open it. Or, in its folder, run the following with your downloaded filename:

chmod +x ActOne.AppImage
./ActOne.AppImage
