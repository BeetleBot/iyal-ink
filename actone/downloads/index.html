RELEASE NOTES / V0.4.15

What's new

  • Large Screenplays & .actone Bundle Save Fix — Resolved a critical saving freeze on large screenplays (80–100+ pages) by restoring synchronous direct zipping (zipSync) and converting byte buffers before Tauri IPC transfer.
  • Infinite Page Breaks Loop Fix — Eliminated a main-thread deadlock in paginateScreenplay where backtracking for consecutive scene headings or character names at page breaks created an infinite pagination loop.
  • Project-Centric Snapshots — Standardized screenplay snapshot backups to save exclusively inside the .snapshots/ folder within your active project directory.
  • Safeguarded Event Cleanup — Wrapped event unlisten handlers with safety guards to prevent crash errors during hot-reloads and unmounts.
