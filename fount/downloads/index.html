Install FountTUI

Get FountTUI running in your favorite terminal environment across Linux, Windows, or macOS.

GitHub Repository & Source Code

Explore source code, submit issues, or clone the repository directly on GitHub.

View on GitHub ↗

Linux Terminal Tarball

Download the latest pre-compiled Linux release tarball from GitHub and run the automated installer script.

tar -xzf Fount-Linux-x64-*.tar.gz && sudo ./install.sh

Windows (Microsoft Store)

Get the verified native Windows build directly from the Microsoft Store with automatic background updates.

Get from Microsoft Store ↗

Universal Rust Cargo Install (Linux / macOS / Windows)

If you have the Rust toolchain installed, you can build and install the latest binary directly from crates.io.

cargo install fount

macOS Terminal Setup

Install via Cargo (cargo install fount). For optimal Catppuccin Mocha theme rendering, use a terminal with 24-bit Truecolor support such as Ghostty, iTerm2, or Kitty.
