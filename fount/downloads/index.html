RELEASE NOTES / V0.11.2

What's new

  • Linux tarball distribution — portable .tar.gz archive ships with install.sh and uninstall.sh for system-wide installation.
  • GitHub release automation — releases are built and pushed as GitHub release assets automatically.
  • PDF export crash fix — no more crashes when exporting large files with dirty formatted Fountain markup.
  • X-Ray theme contrast — character pair names in the Interactions panel now inherit the theme foreground, staying readable in light themes.
