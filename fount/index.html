A distraction-free, blazingly fast terminal screenplay editor built for writers who live in the keyboard. Outline, write, and export industry-standard scripts without ever leaving your terminal.

01 // PERFORMANCE

Sub-4ms Latency

Zero web runtimes, zero garbage collector pauses. Pure Rust compilation renders every keypress instantly to ANSI buffers.

02 // FOOTPRINT

< 15MB Memory

Light enough to run smoothly on a Raspberry Pi, inside tmux over SSH, or alongside heavyweight compilation pipelines.

03 // FORMAT INTEGRITY

100% Plain Fountain

Your stories remain human-readable forever. Commit to git repositories, diff scene revisions, and edit with standard Unix tools.

04 // INTEROPERABILITY

Studio-Ready Exports

One-key export to industry-standard Final Draft (.fdx), Fade In (.fadein), formatted PDF, and standalone HTML.

02 // ARCHITECTURE & CAPABILITIES

Engineered for keyboard velocity.

Everything you need to outline, draft, analyze, and format feature screenplays without touching a mouse.

01 Ctrl + N

Fountain, Rendered Live

Write in standard Fountain syntax and watch scene headings, character dialog, parentheticals, and transitions format automatically in real time.

  • Instant home-row navigation across scenes and acts
  • Scene number auto-indexing and page estimation
  • Automatic character cue capitalization and auto-complete
ZOOM PREVIEW 🔍
02 F2 / Tab

Index Cards & Beat Tree

Step back from the text with an interactive TUI Corkboard. Reorder beats, group sequences into 3-Act or Hero's Journey structures with instant visual feedback.

  • Hierarchical outline tree with collapsible acts
  • Interactive index cards with synopsis and emotional beats
  • Instant re-sequencing without breaking Fountain structure
ZOOM PREVIEW 🔍
03 F3 / :xray

X-Ray Pacing & Analysis

Deep analytical inspection of your screenplay directly in the terminal—monitor dialogue vs. action density, scene timing distribution, and character co-occurrence charts.

  • Real-time dialogue vs. action pacing histograms
  • Character dialogue frequency and scene presence graphs
  • Estimated running time breakdown per sequence
ZOOM PREVIEW 🔍
04 F4 / :sprint

Writing Sprint Speedometer

Set timed writing sprints with live words-per-minute velocity calculation, session milestones, and automatic snapshots to keep you locked in deep flow state.

  • Customizable sprint intervals (15m, 25m Pomodoro, 60m)
  • Real-time WPM speedometer and word-count delta metrics
  • Automated session snapshot archives preventing any loss
ZOOM PREVIEW 🔍
05 Ctrl + F / /

Instant Regex Search

Global text search and multi-line replacement designed for high-velocity editing. Search character names, dialogue patterns, and markers across 120-page drafts.

  • Sub-millisecond full-script regex search
  • Interactive match preview list with instant jump-to-line
  • Safe multi-file and character batch renaming
ZOOM PREVIEW 🔍
06 :theme

High-Contrast Terminal Themes

Custom-tailored color themes designed to match your terminal setup—from phosphor amber and cyber matrix to catppuccin mauve and monochrome e-ink.

  • Native 16-color ANSI and 24-bit TrueColor support
  • Distraction-free typewriter focus modes
  • Custom JSON theme definition files supported
ZOOM PREVIEW 🔍

03 // DESIGN PHILOSOPHY

"The fastest screenplay is written when nothing stands between your fingers and the page."
FOUNTTUI MANIFESTO // 2026

Zero GUI Clutter

No popups, toolbars, or floating dialogs. Your entire narrative canvas is focused on typography and story structure.

Vim & Emacs Synergy

Familiar ergonomic keybindings, instant buffer navigation, and full command-line piping capabilities for power users.

Git-Native Revisioning

Because Fountain files are clean UTF-8 text, you get pristine branch diffs, collaborative merges, and permanent ownership.

Free & Open Source

Licensed under MIT / Apache-2.0. No subscriptions, no cloud vendor lock-in, and zero analytics telemetry.
