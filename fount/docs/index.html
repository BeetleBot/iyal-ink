FountTUI Documentation

Official Wiki and reference manual for FountTUI v0.11.0. Everything you need to master terminal screenwriting.

Overview

FountTUI is a lightweight terminal-based screenplay editor written in Rust. It reads and writes plain-text .fountain markup files natively while providing instant syntax highlighting, structure navigation, and analytical breakdown tools.

Developer's Note on Pagination

Due to TUI font rendering variance, page counts displayed in the editor buffer are close approximations. PDF exports generated via ActOne Screenplay or Fountain CLI contain the exact page layout.

Installation Guide

FountTUI can be installed on Linux, macOS, or Windows using binary packages or Cargo.

Linux Tarball

wget https://github.com/BeetleBot/FountTUI/releases/download/v0.11.0/Fount-Linux-x64-v0.11.0.tar.gz tar -xzf Fount-Linux-x64-v0.11.0.tar.gz sudo ./install.sh

Via Cargo (Cross-Platform)

cargo install fount

Fountain Syntax Guide

FountTUI uses the standard Fountain syntax. Here is a cheat sheet of elements recognized by the parser:

Element Fountain Syntax Example
Scene Heading Starts with INT., EXT., INT./EXT. INT. COFFEE SHOP - DAY
Character ALL CAPS line preceded by blank line ARTHUR
Parenthetical Wrapped in parentheses under character (whispering)
Transition ALL CAPS ending in TO: or > prefix CUT TO:
Centered Text Wrapped in > < > THE END <

Keyboard Shortcuts

Master these core hotkeys to navigate FountTUI without touching a mouse:

Key Combination Action
Ctrl + T Toggle Scene Tree Navigator side panel
Ctrl + K Open Story Architect Index Cards view
Ctrl + X Toggle X-Ray Scene & Character Metrics
Ctrl + P Open Quick Scene Search palette
F2 Cycle Themes (Catppuccin, Nord, Everforest, Lilac)

Scene Tree Navigation

Pressing Ctrl+T reveals the Scene Tree panel. It parses your script's scene headings and section markers (# Act I, ## Sequence A) into an interactive nested hierarchy.

Story Architect Cards

Pressing Ctrl+K transforms your terminal view into a grid of index cards. Each card represents a scene heading and its synopsis text. You can edit scene summaries directly in card view.

X-Ray Analysis

X-Ray mode provides real-time analytical metrics of your screenplay, including dialogue distribution percentages among characters, scene length histograms, and location breakdown lists.
